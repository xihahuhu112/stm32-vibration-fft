# 03 · 编译与环境

## 1. 环境要求

| 项 | 版本 |
|---|---|
| IDE | Keil MDK-ARM（本工程用 **AC5 v5.06 update 7**，位于 `D:\Keil5\Core\ARM\ARMCC`） |
| 器件包 | `Keil.STM32F4xx_DFP.2.17.1` |
| 代码生成 | STM32CubeMX 6.11.1 + `STM32Cube FW_F4 V1.28.3` |
| 下载器 | ST-Link V2（Keil 里选 ST-Link Debugger） |

## 2. Drivers 目录为什么不在仓库里

`Drivers/` 是 CubeMX 生成的 HAL 驱动 + CMSIS 器件头文件 + 手工拷入的 CMSIS-DSP 源码，合计约 45 MB，全部提交会让仓库变得很重，所以 `.gitignore` 忽略了它。**还原方法**（也提供了脚本 `tools/restore-drivers.ps1`）：

1. **HAL 驱动与 CMSIS 器件头**：用 CubeMX 打开 `VibrationMonitor.ioc` → 点 `GENERATE CODE`，会自动重建 `Drivers/STM32F4xx_HAL_Driver/` 与 `Drivers/CMSIS/Device`、`Drivers/CMSIS/Include`。
   （注意：重新生成**不会**清空工程里已加的 `App` 与 `Drivers/CMSIS/DSP` 分组，这一点已实测确认。）
2. **CMSIS-DSP**：从 Keil 的 CMSIS 包里拷（本例 `D:\Keil5\Pack\ARM\CMSIS\5.9.0\CMSIS\DSP`），工程只需要以下文件：

```
Drivers/CMSIS/DSP/Include/            根目录 5 个头 + dsp/ 子目录 30 个头
Drivers/CMSIS/DSP/Source/TransformFunctions/
    arm_rfft_fast_f32.c
    arm_rfft_fast_init_f32.c
    arm_cfft_f32.c
    arm_cfft_init_f32.c
    arm_cfft_radix8_f32.c
    arm_bitreversal2.c          ← 必须用 .c 版，不要用 arm_bitreversal2.S
Drivers/CMSIS/DSP/Source/CommonTables/
    arm_common_tables.c
    arm_const_structs.c
```

> ⚠️ 踩坑记录：`arm_bitreversal2.S` 是 GNU 语法汇编，AC5 会报几十个 `A1163E/A1137E`，必须换成 `arm_bitreversal2.c`；另外 `arm_cfft_radix8_f32.c`、`arm_cfft_init_f32.c` 缺了会在链接阶段报 `arm_radix8_butterfly_f32` / `arm_cfft_init_f32` 未定义。

## 3. Keil 工程必须的设置（重新生成后逐项核对）

| 位置 | 设置 |
|---|---|
| Options → Device | `STM32F407VGTx` |
| Options → C/C++ → Define | `USE_HAL_DRIVER,STM32F407xx,ARM_MATH_CM4` |
| Options → C/C++ → Include Paths | `../Inc;../Inc/App;../Drivers/CMSIS/DSP/Include;../Drivers/STM32F4xx_HAL_Driver/Inc;../Drivers/STM32F4xx_HAL_Driver/Inc/Legacy;../Drivers/CMSIS/Device/ST/STM32F4xx/Include;../Drivers/CMSIS/Include` |
| Groups | `App`（mpu6050.c / ssd1306.c / fft_analyzer.c / sampler.c）、`Drivers/CMSIS/DSP`（上列 8 个源文件） |
| Options → Debug | 右侧选择 **ST-Link Debugger**，Port = **SW**，能读出 IDCODE |
| Options → Utilities → Settings | 勾 `Reset and Run`；Flash Download 里加 **STM32F4xx 1MB Flash** 算法 |
| `Inc/stm32f4xx_hal_conf.h` | `#define HAL_TIM_MODULE_ENABLED`（CubeMX 配了 TIM3 后会自动打开） |

## 4. 编译

```powershell
& 'D:\Keil5\Core\UV4\UV4.exe' -b '<工程路径>\MDK-ARM\VibrationMonitor.uvprojx' -j0 -o '<日志路径>\build.log'
```

查日志末尾应为：

```
Program Size: Code=16316 RO-data=121380 RW-data=48 ZI-data=25568
"VibrationMonitor\VibrationMonitor.axf" - 0 Error(s), 0 Warning(s).
```

> 若上次是增量编译失败，**再跑一次**通常就过（.o 已生成但链接用了旧状态）。

## 5. 烧录

1. Keil 里点 **F8（Download）**，或独立用 STM32CubeProgrammer 下载 `MDK-ARM/VibrationMonitor/VibrationMonitor.hex`。
2. 首次烧完务必确认 **Reset and Run 已勾选**，否则程序停在复位状态屏幕不亮。
3. 若报 `No ST-LINK detected`：先装驱动 `STSW-LINK009`，再换 USB 口（避开部分克隆版不认的 USB3.0 口）；**不要点固件升级**。
