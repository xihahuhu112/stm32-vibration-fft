# 02 · 原理与参数

## 1. 采样：为什么是 1 kHz / 1024 点

- TIM3 挂在 APB1（定时器时钟 84 MHz），**PSC = 83** → 计数频率 1 MHz；**ARR = 999** → 每 1000 个计数溢出一次 = **1 kHz 更新中断**。
- 每块采 **1024 点**，耗时 1024 ms ≈ 1.02 s。
- 频率分辨率 `Δf = fs / N = 1000 / 1024 ≈ 0.977 Hz`。
- 可分析带宽上限为 Nyquist 频率 `fs/2 = 500 Hz`，但传感器自身数字低通为 44 Hz，实际有效范围 ≈ 0~44 Hz，远低于 Nyquist，**不会混叠**。

> 取舍：同一块长度下，降低 fs → 分辨率变好但能测的频率上限降低；提高 N → 分辨率变好但内存与计算量上升、刷新变慢。

## 2. 预处理三步

| 步骤 | 目的 | 实现 |
|---|---|---|
| 4 点滑动平均 | 抑制高频随机噪声（等效最简 FIR 低通） | `FFT_MovingAverage(data, N, 4)`，边缘钳位 |
| 去直流 | 去掉重力造成的固定偏置，否则频谱 0 Hz 处有巨大峰 | `FFT_RemoveDC()`，减去块内均值 |
| 汉宁窗 | 降低截断造成的频谱泄漏（矩形窗旁瓣高，弱信号易被强信号旁瓣淹没） | `FFT_HannWindow()`，逐点乘 `0.5-0.5cos(2πn/(N-1))` |

代价：汉宁窗使主瓣变宽（约 2 个 bin），幅度需乘 2 修正；本项目的用途是"看主频位置"，不追求绝对幅值精度。

## 3. FFT 与幅值谱

使用 CMSIS-DSP 的实数 FFT `arm_rfft_fast_f32`（F407 带 FPU，1024 点耗时毫秒级）：

- 输出排列：`out[0]` = 直流，`out[1]` = Nyquist，之后 `out[2k]` / `out[2k+1]` 为第 k 个频点的实部/虚部。
- 幅值：`mag[k] = sqrt(re² + im²)`，`k = 0..N/2`。
- 第 k 个 bin 对应的频率：`f = k * fs / N`。

## 4. 找峰

- 跳过 `bin 0..1`（直流与极低频），在 **bin 2..120** 内找最大值 → 对应 **≈1.95 Hz ~ 117 Hz**。
- 主频 = `peak_bin * fs / N`，串口打印 `PEAK=xx.x Hz bin=xx`。

## 6. 采样中断的健壮性

- 中断内 I2C 读超时设为 **5 ms**（400 kHz 下 6 字节突发读只需约 0.2 ms），避免单次失败把 1 ms 周期撑爆。
- 连续失败 20 次则提前结束当前数据块（用已有数据继续），防止硬件掉线时主循环永久等待。
