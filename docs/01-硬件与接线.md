## 2. 接线表（全部共地）

### MPU6050（GY-521）

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| VCC | 3.3V | **不要接 5V** |
| GND | GND | 与 OLED、MCU 共地 |
| SCL | PB6 | I2C1_SCL |
| SDA | PB7 | I2C1_SDA |
| XDA / XCL / AD0 / INT | 不接 | AD0 悬空 = 地址 0x68 |

### OLED（SSD1306）

| 模块引脚 | 接到 | 说明 |
|---|---|---|
| VCC | 3.3V | — |
| GND | GND | — |
| SCL | PB6 | 与 MPU6050 共用总线 |
| SDA | PB7 | 与 MPU6050 共用总线 |

### ST-Link V2 → 板子（SWD）

| ST-Link | 板子 |
|---|---|
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V | 3.3V |

### 串口（可选，看 `PEAK=xx.x Hz`）

| 板子 | USB-TTL（CH340） |
|---|---|
| PA9 (TX) | RX |
| PA10 (RX) | TX |
| GND | GND |

## 3. 接线示意

```
                    ┌──────────────┐
  3.3V ──┬──────────┤ VCC          │ GY-521
  GND  ──┼──┬───────┤ GND          │
         │  │       │ SCL ───────────── PB6
         │  │       │ SDA ───────────── PB7
         │  │       └──────────────┘
         │  │       ┌──────────────┐
         │  └───────┤ GND          │ OLED
         └──────────┤ VCC   SCL ─────── PB6
                    │       SDA ─────── PB7
                    └──────────────┘
```

## 4. 三条必须遵守的规则

1. **MPU6050 的 VCC 只能接 3.3V**。
2. **不要双路供电**：ST-Link 已在供 3.3V，就不要再插板载 USB。
3. **改接线必须先断电**，插好再上电；每次上电前用万用表蜂鸣档量 3.3V 与 GND，响了就别上电。

## 5. 分三步验证（不要一次全插）

1. 只接 ST-Link → 烧一次程序，确认下载通路正常。
2. 加 OLED → 上电屏幕出现 `STM32 VIB MONITOR`，说明 I2C 通。
3. 加 MPU6050 → 1 秒内出现 `PEAK=xx.x Hz` + 波形 + 频谱柱，全链路通。

哪一步没过，问题范围就锁定在那一步，不用全盘排查。
