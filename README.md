# STM32F407 + MPU6050 振动信号采集与频谱分析仪

> 课程《信息获取与检测技术》期末项目 —— 用 MEMS 加速度计采集振动，经数字滤波后在 MCU 上做 FFT，实时在 OLED 上显示时域波形与幅值谱，并输出振动主频。

| 项目 | 参数 |
|---|---|
| 主控 | STM32F407VGT6（Cortex-M4 + 硬件 FPU，168MHz） |
| 传感器 | MPU6050（MEMS 电容式三轴加速度计，I2C 数字输出，内建 16bit ADC） |
| 采样 | TIM3 硬件定时中断，**1 kHz**，每块 **1024 点** |
| 频率分辨率 | 1000 / 1024 ≈ **0.98 Hz** |
| 频谱算法 | ARM 官方 CMSIS-DSP `arm_rfft_fast_f32`（实数 FFT） |
| 显示 | 0.96" I2C OLED（SSD1306，128×64）：上半时域波形，下半 63 根幅值谱柱 |
| 输出 | USART1 115200 打印 `PEAK=xx.x Hz` |

---

## 一、它做什么

1. TIM3 每 1 ms 触发一次中断，从 MPU6050 突发读 6 字节三轴加速度（本方案取 X 轴）。
2. 采满 1024 点后，依次做 **4 点滑动平均 → 去直流 → 汉宁窗 → 实数 FFT**。
3. 在 2~120 号谱线里找最大值（约 2~117 Hz），换算成主频。
4. OLED 上半屏画时域波形、下半屏画幅值谱柱状图；串口同步打印峰值频率。
5. 静止时波形平直、频谱无峰；敲击板子后时域振荡、频谱在对应频点出现突起 —— 以此演示"振动 → 频谱特征频率"的完整链路。

## 四、软件结构

```
Src/
├── main.c            # CubeMX 生成 + 用户代码段（主循环：采集→处理→绘图→串口）
├── App/
│   ├── mpu6050.c/h   # MPU6050 驱动：WHO_AM_I 自检、初始化、6 字节突发读
│   ├── sampler.c/h   # TIM3 1kHz 中断采样，采满 1024 点置位
│   ├── fft_analyzer.c/h # 滑动平均 / 去直流 / 汉宁窗 / 实数 FFT / 找峰
│   └── ssd1306.c/h   # OLED 帧缓冲、画点/线/填充矩形、5×7 字库
Inc/
└── App/              # 上述模块头文件
```

关键参数：

| 参数 | 值 | 位置 |
|---|---|---|
| 采样率 | 1 kHz | TIM3：PSC=83、ARR=999（84MHz→1MHz→1kHz） |
| 数据块长度 | 1024 | `FFT_N`（`fft_analyzer.h`） |
| 传感器量程 | ±4 g | `ACCEL_CONFIG = 0x08` |
| 传感器低通 | 44 Hz | `CONFIG = 0x03` |
| 找峰范围 | bin 2~120（≈2~117 Hz） | `FFT_PeakBin(mag, 2, 120)` |

## 七、已知限制

1. 传感器自身数字低通为 44 Hz，**只能测低频振动**；高速振动（如 300 Hz 以上）看不到。
2. 频率分辨率 0.98 Hz 由 1 kHz / 1024 点决定；想更细必须增加点数或降低采样率，二者互相牵制。
3. 1024 点单块无重叠、无平均，幅值谱抖动较大，课程演示够用。
4. 频谱柱只画到约 61 Hz（63 根柱 × 2 px），更高频段未显示。
5. 目前是面包板接线，敲击剧烈时可能出现接触不良导致的偶发断点。
